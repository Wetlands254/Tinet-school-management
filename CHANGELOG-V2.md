# V2 Changelog

## 2026-09-05

### Added
- Term/year-aware fee structures.
- Academic period management.
- Term/year-aware subject configurations.
- Bulk subject assignment to all classes, ECDE, Primary, or Junior.
- Subject deactivate/reactivate controls.
- Per-subject weekly lesson frequency and double-lesson settings.
- Historical-mark preservation when subjects are deactivated.
- Updated Supabase schema with `academic_periods` and `class_subject_offerings`.

### Preserved
- Existing learner, teacher, marks, attendance, report, ranking, timetable, backup and audit features.
- Existing V1 browser data is migrated when V2 starts.
