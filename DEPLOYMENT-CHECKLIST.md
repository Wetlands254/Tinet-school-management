# Tinet deployment checklist

- [ ] Confirm correct Tinet Supabase project URL and publishable/anon key.
- [ ] Back up existing Tinet records before any migration.
- [ ] Apply reviewed SQL to a test project first.
- [ ] Create authorised staff accounts only.
- [ ] Test learner, marks, attendance, fees, reports, rankings, timetables and imports/exports.
- [ ] Test mobile layout and print/PDF workflows.
- [ ] Tighten database policies before production and before parent/student access.
- [ ] Configure server-side M-PESA and messaging integrations separately.
- [ ] Verify backups and recovery.
- [ ] Deploy and train school staff.
